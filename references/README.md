# Acervo de Referências Bibliográficas

Este diretório armazena o arquivo formal `references.bib` contendo as fontes primárias e secundárias fundamentadas utilizadas na documentação do projeto **Software Metrics Learning**.

## Regras de Integridade Acadêmica

1. **Fontes Verificadas**: Nenhuma citação, DOI, edição ou metadado foi inventado.
2. **Fontes Primárias**:
   - **IEEE Computer Society SWEBOK V4.0a**: Guia de corpo de conhecimento de engenharia de software.
   - **IFPUG CPM (Counting Practices Manual)**: Padrão oficial de Análise de Pontos de Função.
   - **ISO/IEC 25010:2023**: Modelo de qualidade de produto de software de 9 características.
   - **Goal-Question-Metric (GQM)**: Trabalhos originais de Victor Basili e publicações SEI/CMU.
   - **Livros texto de referência**: Fenton & Bieman (2014), Pressman & Maxim (2019), Sommerville (2015) e Kan (2002).
