# Exercícios: Paradigma GQM

---

### Exemplo 01 🟢 (Básico - Identificação de Elementos)
Identifique os 5 elementos de Basili no seguinte objetivo:  
*"Avaliar o processo de testes automatizados com o propósito de aumentar a cobertura de código sob o ponto de vista do Líder Técnico no contexto do projeto Sistema de Biblioteca."*

---

### Exemplo 02 🟡 (Intermediário - Derivação de Perguntas)
Dado o objetivo *"Melhorar a previsibilidade de entregas das sprints sob o ponto de vista do Scrum Master"*, formule 2 perguntas (Questions) e derive 2 métricas (Metrics) para cada uma.

---

### Exemplo 03 🔴 (Desafio - Construção de Árvore GQM)
Monte uma árvore GQM completa (Goal, 3 Questions, e pelo menos 4 Metrics) para uma organização cujo objetivo principal de negócio seja *"Reduzir o custo de manutenção corretiva pós-release de sistemas legados sob a ótica da Diretoria de TI"*.
