# Exercícios: Fundamentos de Métricas

---

### Exemplo 01 🟢 (Básico - Conceitual)
Classifique os elementos abaixo em **Medida**, **Métrica** ou **Indicador**:
1. "45 defeitos reportados no sistema de bilhetagem."
2. "4.5 defeitos por KLOC."
3. "Aviso: A densidade de defeitos está 30% acima do teto de qualidade permitido para homologação."

---

### Exemplo 02 🟢 (Básico - Classificação)
Diferencie uma Métrica Direta de uma Métrica Indireta. Classifique as métricas abaixo:
- Horas de esforço apontadas no timesheet
- Produtividade (LOC/h)
- Linhas de Código (LOC)
- Densidade de Defeitos (Defeitos/PF)

---

### Exemplo 03 🟡 (Intermediário - Interpretação)
Uma equipe de desenvolvimento orgulha-se de ter aumentado sua contagem diária de linhas de código escritas de 100 LOC/dia para 300 LOC/dia após a troca de linguagem. Explique os riscos de avaliar a melhoria do time utilizando apenas essa métrica.

---

### Exemplo 04 🔴 (Desafio - Análise de Cenário)
Um gerente de projetos recebe o relatório afirmando que o Projeto A teve 80 defeitos e o Projeto B teve 20 defeitos. O gerente conclui imediatamente que o Projeto A tem pior qualidade do que o Projeto B. Sabendo que o Projeto A possui 40 KLOC e o Projeto B possui 2 KLOC, analise criticamente a conclusão do gerente.
