### Solução do Exemplo 04 🔴
a)
- **Projeto X (C++)**: $50.000 / 1.000 = 50\text{ LOC/hora}$
- **Projeto Y (Python)**: $10.000 / 500 = 20\text{ LOC/hora}$

b) C++ exige maior verbosidade para implementar as mesmas estruturas do que Python. Dizer que o time C++ foi mais produtivo ignorando a expressividade da linguagem é uma falácia, pois o projeto Python entregou a mesma aplicação em metade do esforço total (500h vs 1000h).
