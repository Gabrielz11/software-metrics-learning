# Módulo 06 — APF (Análise de Pontos de Função)

A Análise de Pontos de Função (APF / *Function Point Analysis - FPA*) é a técnica padronizada pela IFPUG para medir o tamanho funcional de um software.

---

## 🎯 Objetivos de Aprendizagem

Ao concluir este módulo, você será capaz de:
- Entender a filosofia da APF como métrica independente de linguagem e tecnologia.
- Distinguir **Funções de Dados** (ALI e AIE) de **Funções Transacionais** (EE, SE e CE).
- Identificar e contar **DET**, **RET** e **FTR**.
- Determinar a complexidade funcional através das tabelas normativas do IFPUG.
- Calcular os Pontos de Função Não Ajustados (PFNA) e aplicar no *Sistema de Biblioteca*.
