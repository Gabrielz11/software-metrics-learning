# Módulo 10 — GQM (Goal-Question-Metric)

O paradigma **Goal-Question-Metric (GQM)**, desenvolvido por Victor Basili na Universidade de Maryland e alinhado aos materiais do Software Engineering Institute (SEI/CMU), é a abordagem metodológica de referência para derivação de métricas de software a partir de objetivos de negócio.

---

## 🎯 Objetivos de Aprendizagem

Neste módulo você aprenderá:
- A filosofia top-down do paradigma GQM.
- Como formular **Objetivos (Goals)** estruturados nos 5 elementos de Basili.
- Como elaborar **Perguntas (Questions)** analíticas e qualitativas.
- Como derivar **Métricas (Metrics)** para responder diretamente a cada pergunta.
- Exemplos práticos aplicados a projetos e ao *Sistema de Biblioteca*.
