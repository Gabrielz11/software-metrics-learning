# Módulo 01 — Fundamentos de Métricas de Software

Bem-vindo ao primeiro módulo do curso de Métricas de Software. O objetivo deste módulo é estabelecer a base conceitual e o vocabulário rigoroso necessário para entender a medição em Engenharia de Software.

---

## 🎯 Objetivos de Aprendizagem

Ao finalizar este módulo, você será capaz de:
- Definir o que é uma métrica de software do ponto de vista teórico e prático.
- Compreender por que a medição é indispensável para o planejamento e controle de projetos.
- Distinguir com clareza os conceitos de **Medição**, **Medida**, **Métrica** e **Indicador**.
- Identificar as diferenças entre **Métricas Diretas** e **Métricas Indiretas**.
