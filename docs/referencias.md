# 📖 Referências Bibliográficas Consolidadas

Este documento consolida as principais fontes de referência bibliográfica primárias e secundárias que fundamentam todo o conteúdo deste repositório educacional.

---

## 🏛️ Normas, Padrões e Guias Oficiais

### IEEE Computer Society — SWEBOK
- **Citação**: IEEE Computer Society. *Guide to the Software Engineering Body of Knowledge (SWEBOK Guide)*, Version 4.0, IEEE Computer Society, 2024.
- **Uso**: Referência geral para conceitos de Engenharia de Software, medição de processos, gestão de projetos e qualidade de software.

### ISO/IEC 25010:2023 — SQuaRE Product Quality Model
- **Citação**: ISO/IEC 25010:2023. *Systems and software engineering — Systems and software Quality Requirements and Evaluation (SQuaRE) — Product quality model*, International Organization for Standardization, Geneva, CH, 2023.
- **Uso**: Fundamentação do modelo de qualidade de produto de software e suas 9 características de qualidade.

### IFPUG — International Function Point Users Group
- **Citação**: IFPUG. *Function Point Counting Practices Manual (CPM)*, Release 4.3.1, International Function Point Users Group, 2010.
- **Uso**: Fundamentação das regras de contagem de Análise de Pontos de Função (ALI, AIE, EE, SE, CE, DET, RET, FTR).

### GQM / GQIM — Carnegie Mellon / Software Engineering Institute (SEI)
- **Citação**: Basili, V. R., Caldiera, G., & Rombach, H. D. *The Goal Question Metric Approach*, Encyclopedia of Software Engineering, John Wiley & Sons, 1994.
- **Uso**: Derivação estruturada de métricas orientadas a objetivos de negócio e perguntas analíticas.
