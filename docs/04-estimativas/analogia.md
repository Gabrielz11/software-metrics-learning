# Estimativa por Analogia

A **Estimativa por Analogia** consiste em estimar o esforço ou custo de um novo projeto comparando-o com projetos semelhantes concluídos no passado pela mesma organização.

---

## 1. Como Funciona

```mermaid
flowchart LR
    A[Novo Projeto X] -->|Compara Atributos| B[Base de Dados Históricos]
    B -->|Identifica Projeto Y Semelhante| C[Ajusta Diferenças de Escopo/Escala]
    C -->|Calcula| D[Estimativa para Projeto X]
```

---

## 2. Passos para Estimativa por Analogia
1. Identificar o novo projeto ou módulo a ser estimado.
2. Buscar na base de dados históricos da organização um ou mais projetos similares.
3. Analisar as semelhanças e diferenças nos fatores de complexidade, tamanho da equipe e tecnologia.
4. Ajustar proporcionalmente o esforço histórico para derivar a nova estimativa.

---

## 3. Vantagens e Limitações

### Vantagens
- Pode ser realizada muito cedo no ciclo de vida do projeto.
- Baseia-se em dados reais executados pela própria equipe (alta aderência ao contexto da empresa).

### Limitações
- Exige uma base de dados histórica estruturada de projetos passados.
- Apresenta falhas se o novo projeto utilizar tecnologias radicalmente diferentes.
