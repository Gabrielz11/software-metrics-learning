# Estimar Software

> 📚 **Conceito fundamentado em referência (McConnell / Pressman)**  
> Estimar é um processo probabilístico de prever o esforço, prazo e custo necessários para construir um sistema de software com base em informações incompletas.

---

## 1. O que é?
Estimar é produzir um intervalo de valores esperados (ex: "entre 400 e 500 horas"), e não um número único determinístico e imutável.

## 2. Por que é tão difícil estimar software?
1. **Intangibilidade**: O software não possui propriedades físicas fixas.
2. **Requisitos Mutáveis**: A compreensão do cliente sobre o problema evolui durante o projeto.
3. **Inovação Técnica**: Praticamente todo software comercial possui componentes inéditos ou integrações com sistemas legados não testados previamente.
