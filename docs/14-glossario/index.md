# 📖 Glossário de Termos e Siglas em Métricas de Software

Glossário alfabético de referência para termos, métodos e siglas utilizadas no repositório.

---

### A
- **AIE (Arquivo de Interface Externa / EIF)**: Grupo de dados correlatos, identificável pelo usuário, referenciado pela aplicação mas mantido externamente por outro sistema (padrão IFPUG).
- **ALI (Arquivo Lógico Interno / ILF)**: Grupo de dados correlatos, identificável pelo usuário, mantido dentro da fronteira da aplicação por um processo elementar (padrão IFPUG).
- **APF (Análise de Pontos de Função / FPA)**: Técnica padronizada pelo IFPUG para medir o tamanho funcional de um software com base nos requisitos do usuário.

### C
- **CE (Consulta Externa / EQ)**: Processo elementar transacional cuja intenção primária é a recuperação e exibição de dados para o usuário sem efetuar alterações ou cálculos (padrão IFPUG).
- **Cycle Time**: Tempo decorrido entre o início ativo do desenvolvimento de uma tarefa e sua conclusão no ambiente de destino.

### D
- **DET (Data Element Type / Tipo de Dado Elementar)**: Campo único, não repetitivo e identificável pelo usuário, utilizado na contagem de complexidade APF.
- **DRE (Defect Removal Efficiency)**: Porcentagem de defeitos removidos pelo processo de qualidade antes do lançamento do software em produção.

### E
- **ECF (Environmental Complexity Factor)**: Fator de complexidade ambiental e de equipe utilizado no ajuste final do cálculo de Use Case Points (Karner).
- **EE (Entrada Externa / EI)**: Processo elementar transacional que processa dados vindos do mundo externo com a intenção de manter um ou mais ALIs (padrão IFPUG).

### F
- **FPA (Function Point Analysis)**: Denominação em inglês para Análise de Pontos de Função (APF).
- **FTR (File Type Referenced / Tipo de Arquivo Referenciado)**: ALI mantido ou lido por uma transação, ou AIE lido por essa transação.

### G
- **GQM (Goal-Question-Metric)**: Abordagem metodológica desenvolvida por Victor Basili para derivação top-down de métricas a partir de objetivos de negócio.

### I
- **IFPUG (International Function Point Users Group)**: Organização internacional sem fins lucrativos que mantém o padrão oficial e o manual CPM da Análise de Pontos de Função.
- **Indicador**: Métrica ou conjunto de métricas comparado a metas ou dados históricos que fornece sinais diretos para orientar decisões de gestão.

### K
- **KLOC (Kilo Lines of Code)**: Unidade equivalente a 1.000 linhas de código física ou lógica.

### L
- **Lead Time**: Tempo total decorrido entre a criação inicial da solicitação pelo cliente e a disponibilização da entrega em produção.
- **LOC (Lines of Code)**: Contagem física de linhas de um código-fonte.

### M
- **McCabe (Complexidade Ciclomática)**: Métrica desenvolvida por Thomas McCabe para quantificar o número de caminhos independentes no grafo de fluxo de controle de um código.
- **Métrica**: Medida quantitativa do grau em que um sistema ou processo possui determinado atributo.
- **MTBF (Mean Time Between Failures)**: Tempo médio em que o sistema opera continuamente entre falhas.
- **MTTR (Mean Time to Repair)**: Tempo médio necessário para reparar e restaurar o sistema após a ocorrência de uma falha.

### P
- **PF (Ponto de Função / Function Point)**: Unidade de medida padronizada de tamanho funcional de software.

### R
- **RET (Record Element Type / Tipo de Registro Elementar)**: Subgrupo de dados reconhecido pelo usuário dentro de um ALI ou AIE.

### S
- **SE (Saída Externa / EO)**: Processo elementar transacional cuja intenção primária é apresentar dados derivados ou calculados ao usuário (padrão IFPUG).
- **SLOC (Source Lines of Code)**: Contagem de linhas de código executáveis, ignorando linhas em branco e comentários.

### T
- **TCF (Technical Complexity Factor)**: Fator de complexidade técnica utilizado no ajuste do método Use Case Points.
- **Throughput**: Quantidade de entregáveis ou itens de trabalho concluídos por unidade de tempo em um fluxo Lean/Kanban.

### U
- **UAW (Unadjusted Actor Weight)**: Somatório ponderado da complexidade dos atores em Use Case Points.
- **UCP (Use Case Points / Pontos por Caso de Uso)**: Técnica de estimativa desenvolvida por Gustav Karner baseada em atores e casos de uso UML.
- **UUCW (Unadjusted Use Case Weight)**: Somatório ponderado da complexidade dos casos de uso em UCP.

### V
- **Velocity**: Volume médio de unidades de trabalho (Story Points ou itens) concluídas por uma equipe durante uma iteração (Sprint).
